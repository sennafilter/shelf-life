Build a website with Claude, then put it online

This is how I made Shelf Life, my library page, without writing any code myself. You describe what you want, react to what you see, save it on GitHub and publish it on Vercel. You can swap the books for anything: a recipe box, a travel log, a portfolio.

Make your own copy See the code on GitHub Deploy it on Vercel
You need
  • Claude (the Code tab in the Claude app)
  • A free GitHub account at github.com
  • A free Vercel account at vercel.com (sign up with GitHub)
1

Say what you want, with a reference

Start with the feeling, not the features. I showed Claude a screenshot of a site I loved and said what I wanted to be different. Pictures help a lot.

What I saidI want to create a website like Goodreads, but way cooler. Here is one I really like: books on a shelf, editorial, real-looking books. I can't copy it exactly, so make mine different.

Say who it's for. Mine said: I like Colleen Hoover and the most popular books, nothing too girly, and I love nonfiction. Claude filled the shelf with books like that.

2

React like a designer

The first version won't be right. Look at it and say plainly what bugs you. Short, honest notes work best, and you don't need design words.

Notes I sent, one at a timeThis is too similar to hers. Maybe other colors, something more retro or editorial. Those lines are gross. These shelves look too much like hers. I want the books to look a little more realistic. I want to be able to see my reads, recommended, to read, and so on.

Each note changed something real: the colors, the shelves (they became a wooden bookcase) and the reading lists.

3

Ask for options before it changes anything

When I wasn't sure about a screen, I asked for mock-ups first. Claude made a separate page with several versions and left the real site alone. I picked one, then it built it in.

What I saidGive me 5 options, static, before changing the website.

If Claude misread you, say so. I asked for book views and meant home screens, said that, and got four home screens.

4

Put it on GitHub

GitHub is where your project lives so you can keep it, share it and change it later. Ask Claude to do it.

What I saidCan you put this on GitHub so I can do it on Vercel?

Claude created a repository called shelf-life with the site in a file named index.html. Claude needs to be logged in to GitHub on your computer to do this (the GitHub app or gh auth login in a terminal). If it asks whether the repo should be public or private, public is what lets other people copy it.

5

Publish it on Vercel

Vercel turns your GitHub repo into a real website address. It's free for personal projects.

  1. Go to vercel.com/new and sign in with GitHub.
  2. Pick your repo.
  3. Set the Framework Preset to Other and leave the rest empty.
  4. Click Deploy. A minute later you have a link.

After that, whenever Claude pushes a change to GitHub, Vercel updates the site by itself.

6

Make it yours

Open the repo, click Use this template, then deploy your copy. Then open it in Claude and change it with plain sentences, like these:

Try theseReplace the books with my own list. Here is a CSV of what I've read. Change the colors to something warmer. Add a page about me and link it in the footer. Make a recipe box instead of a library, same bookcase look.

The shelf is one HTML file, so it's easy to change. Your ratings and reading lists are saved in your own browser.
